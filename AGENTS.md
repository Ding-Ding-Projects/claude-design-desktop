# Repository guidance

This file is a sanitized project mirror of the shared instructions. Keep the mirror current when the canonical instructions change. Preserve the repository's ordinary public vocabulary in committed files, keep private data out of source and documentation, and do not claim an unverified build, release, capture, or deployment.

The site lane owns only `site/`, `docs/`, and the root documentation files assigned to it. Use focused checks, keep the hand-written feature inventory synchronized with article files, and leave desktop runtime and packaging changes to their owning lanes.
