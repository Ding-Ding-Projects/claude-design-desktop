# Contributing

Keep changes scoped, reviewable, and truthful. Public documentation uses ordinary professional language and never includes credentials, private vocabulary data, browser state, or unverified release links.

Before changing the site or article inventory, run `node site/test-static.mjs`. Add a hand-written inventory row and a feature article together. Do not add remote assets, CDN dependencies, analytics, generated images, or sample account data. UI claims must identify whether they are implemented, pending integration, or unverified.
