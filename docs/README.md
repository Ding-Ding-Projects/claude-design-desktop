# Documentation

This folder is the source for the bundled offline documentation browser and the public documentation site. Every article describes behavior, configuration, failure handling, security boundaries, and verification status. The current extraction baseline is `4a3c267e7e22f6636a02542554309cd49cd41e9d`.
