# Command palette

## Behavior

`Ctrl+Shift+F` opens a palette containing destinations, features, settings, articles, and appearance controls. Results expose rich controls where a setting can be changed and teleport to the exact target.

## Configuration

Palette size is a persisted user choice between bounded-card and full-window views. Search remains plain text until regex is deliberately enabled.

## Failure and security

Unknown commands do not execute. Locked targets prompt at the target boundary instead of bypassing a lock. Palette input stays local.
