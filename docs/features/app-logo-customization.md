# App-logo customization

## Behavior

The app offers shipped presets and local custom-image upload with crop, fit, focal point, safe area, transparent/background treatment, and previews at consumed sizes.

## Configuration

Accepted images are decoded locally with bounded bytes, pixels, frames, dimensions, memory, and time. Derived display assets and selection persist only in local app or browser storage.

## Failure and security

Signature mismatch, malformed, animated, oversized, or unsupported input is rejected without partial application. Conversion loss is disclosed, and stable app identity never changes.

## Verification

Verify presets, upload, crop, conversion, rollback, cache corruption, replace, reset, no-network behavior, accessibility, and packaged rendering. Integrated evidence is pending.
