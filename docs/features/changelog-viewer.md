# Changelog viewer

## Behavior

The viewer covers every released version with exact dates, categorized changes, and links to the completing commit. Search and date range filters compose, and the current selection can be copied or exported.

## Configuration

Date input accepts the locale format and ISO values. The calendar supports month/year jumps, ranges, and named presets while preserving typed input.

## Failure and security

Unknown or missing commits are shown as unavailable rather than linked to a guessed neighbor. Provider-authored notes are rendered through the shared isolated renderer.

## Verification

Verify entry inventory, commit existence, date parsing, invalid partial input, search regex, copy, Markdown export, accessibility, and empty states. No release entries are invented in this preview.
