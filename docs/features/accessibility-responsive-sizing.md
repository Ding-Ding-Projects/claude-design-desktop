# Accessibility and responsive sizing

## Behavior

All surfaces support keyboard operation, visible focus, correct roles and names, contrast, reduced motion, screen-reader announcements, and touch-sized controls. Content responds from approximately 320px without body-wide horizontal scrolling.

## Configuration

Theme, density, font size, and reduced-motion preferences apply live where feasible. Wide tables and code blocks scroll inside their own containers.

## Failure and security

Unsupported assistive features are announced rather than silently omitted. Overlays remain bounded and scrollable, and no focus trap hides the escape path.

## Verification

Verify keyboard-only navigation, screen-reader semantics, high contrast, reduced motion, 320px layouts, bilingual strings, and 100/125/150/200 percent display scales. Final built evidence is pending.
