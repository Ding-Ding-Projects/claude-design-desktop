# Bulk actions

## Behavior

Every list supports multi-select, ranges, inverse selection, scoped select-all, and the actions that exist for one item. A preview states selected and affected counts before mutation.

## Configuration

Long operations expose progress, cancellation, partial outcomes, and undo through local history. Search and regex filters compose with selection.

## Failure and security

Skipped items are named with reasons. Destructive batches use the two-key confirmation gate, preserve pinned and locked exclusions by default, and never treat partial completion as whole-batch success.

## Verification

Verify list, table, notification, history, converter, and model-store paths, keyboard selection, progress, cancellation, undo, export, and destructive previews. Integrated evidence remains pending.
