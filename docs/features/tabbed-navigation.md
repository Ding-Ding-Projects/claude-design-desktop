# Tabbed navigation

## Behavior

The content surface uses browser-style tabs. A strip can dock left, right, top, or bottom, with left as the default. Tabs support overflow, reorder, pinning, grouping, collapse, four independent discovery searches, and text-based bulk close actions.

## Configuration

Order, pinned state, groups, dock edge, appearance, and collapsed state persist locally. Moving a tab into a group uses a searchable picker.

## Failure and security

Pinned or locked tabs are excluded from bulk close by default. Unsaved-work protection and explicit previews prevent accidental closure. Locked tabs remain discoverable and prompt for their own unlock.

## Verification

Verify all dock edges, keyboard roving focus, vertical orientation, overflow, groups, searches, bulk-close inverse predicates, responsive collapse, and restart persistence. Integrated built evidence remains pending.
