# Personal vocabulary upload

## Behavior

Every app and page shows a local JSON upload control before a file exists. A valid bounded file can alter user-facing private wording; until then the original shipped wording remains active.

## Configuration

The versioned schema limits bytes, depth, entries, keys, values, and allowed fields. Replace, clear, reset, and cache status are visible, searchable, localized, and accessible.

## Failure and security

Malformed, duplicate-key, unknown-version, oversized, unsafe-key, or unexpected-field payloads are rejected without partial application. No path, payload, or replacement is sent to a network or public record.

## Verification

Verify empty, valid, invalid, replace, clear, cache corruption, reload, no-network, School mode suppression, all language modes, keyboard access, and accessible names. The canonical private payload is never included here.
