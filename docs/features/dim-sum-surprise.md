# Dim sum surprise

## Behavior

At startup a local ten-percent draw may show one bilingual dish name and a bundled or public-catalog-linked image. It is non-blocking, does not steal focus, and is suppressed during first-run, error, update, or active-task flows.

## Configuration

There is no opt-out control. Each launch uses one fresh draw, and the active language mode controls the surrounding copy.

## Failure and security

Missing public image assets are omitted honestly. Product repositories do not generate, scrape, or vendor catalog photos. Images and alt text remain local or use the approved public catalog route.

## Verification

Verify probability bounds, no double display, suppression states, accessibility alt text, reduced motion, and language/funny-level behavior. Release catalog evidence remains pending.
