# Status Hub

## Behavior

The live status surface shows current state, last update, verified baseline, active lanes, evidence, next checks, and questions. It updates in place and stays responsive from approximately 320px.

## Configuration

Each project registers its repository, default branch, release channel, checks, links, and task item. The site source uses an honest local fallback when an authenticated status service is unavailable.

## Failure and security

Unrun checks remain unrun. Question controls report whether delivery was confirmed. Webhook credentials and private payloads stay on the protected host boundary.

## Verification

Verify current timestamps, lane links, interactive filters, keyboard/touch operation, question delivery confirmation, mobile layout, and no fabricated verdicts. Remote deployment is not claimed here.
