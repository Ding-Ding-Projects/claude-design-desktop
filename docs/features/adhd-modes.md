# ADHD modes

## Behavior

Five independent, off-by-default interface accommodations are available: Focus, Low stimulation, Time awareness, One thing at a time, and Momentum. They never hide work without an obvious return path and never make medical claims.

## Configuration

Each mode persists independently, participates in language, funny-level, scheduling, history, export, and reset behavior, and can be discovered through search and the command palette.

## Failure and security

Copy states facts without judgement, rankings, streaks, or guilt. Momentum prompts are dismissible and respect a stated quiet period. Modes are local preferences.

## Verification

Verify each mode alone and in combinations, persistence, School mode interaction, reduced motion, notifications, keyboard, screen-reader copy, narrow layout, and export. Built evidence remains pending.
