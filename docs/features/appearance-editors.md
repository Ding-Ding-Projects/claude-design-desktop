# Appearance editors

## Behavior

Every rendered element exposes an appearance editor from its context menu and keyboard equivalent. The editor is anchored, non-modal, reversible, and covers typography, color, shape, elevation, motion, image treatment, and interaction states.

## Configuration

Appearance values, named presets, imports, exports, and reset operations are persisted locally. Unsupported properties remain visible with a capability explanation.

## Failure and security

Failed conversions retain the prior valid appearance. Imported values are bounded and validated. Stable product identity never derives from display styling.

## Verification

Verify per-element targeting, state inheritance, undo and redo, reset, contrast, reduced motion, font fallback, continuous color translation, animated rainbow sentinel, and narrow layouts. Final built evidence is pending.
