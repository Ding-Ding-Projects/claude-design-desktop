# Destructive confirmation

## Behavior

Irreversible actions name the exact affected data and require two independently operated keys before a full-range confirmation slider enables. The animation is non-blocking and reduced-motion aware.

## Configuration

The gate is implemented in the native product surface and returns focus to the originating control. Escape and Emergency exit cancel without changing data.

## Failure and security

No destructive operation runs on one key, partial slider movement, stale handles, or alternate shortcuts. Confirmation records redacted action metadata only.

## Verification

Verify untouched, one-key, two-key, partial, complete, cancellation, keyboard, assistive technology, reduced motion, localization, and real success/failure paths. Integrated evidence is pending.
