# Notification centre

## Behavior

Informational, progress, success, and non-decision errors use corner notifications. Warnings and errors remain until dismissed. A searchable notification centre preserves dismissed records and supports bulk actions.

## Configuration

Notifications are localized, accessible, and persisted in a bounded local history. Actions such as retry, undo, open, and details are real controls.

## Failure and security

Duplicate delivery is coalesced by operation ID. Notification records omit credentials, private vocabulary content, and raw upstream response bodies.

## Verification

Verify stacking, timeout, dismissal, keyboard focus, screen-reader announcements, retry and undo actions, search, bulk dismiss, and export. Integrated evidence is pending.
