# Language modes

## Behavior

The product offers English, playful Hong Kong Cantonese, and bilingual presentation. Bilingual copy keeps the primary label prominent and puts the translated line beside or below it. Technical identifiers, file paths, version numbers, and external records are not rewritten.

## Configuration

The selected mode is persisted locally and can be changed from every app-owned settings surface. School mode temporarily forces English while preserving the previous selection for restoration.

## Failure and security

Missing localized strings fall back to English and surface a non-blocking notice. Language data is bundled or locally stored; no translation request is made for normal rendering.

## Verification

The feature check covers all three modes, restart persistence, bilingual narrow layouts, keyboard navigation, and screen-reader names. The integrated build still needs the final real-artifact evidence.
