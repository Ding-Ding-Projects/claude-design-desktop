# Ollama suite manager

## Behavior

The manager uses the documented local HTTP API for health, models, tags, pulls, chat, and capability metadata. Its Model Store enumerates every published variant at each verified refresh and reconciles installed state.

## Configuration

Catalog identity, timestamp, page count, completeness, stale age, hardware evidence, batch parallelism, chat parameters, and allowlisted harness profiles are visible and persisted locally.

## Failure and security

Missing, stopped, unhealthy, offline, insufficient-storage, and incompatible states provide bundled guidance. Harness launch is allowlisted and snapshotted; arbitrary shell and payment semantics are not accepted.

## Verification

Verify exhaustive pagination, fit evidence, pull progress and partial outcomes, streamed chat, capability-gated attachments, preflight, rollback, offline states, and secret exclusion. Integrated evidence remains pending.
