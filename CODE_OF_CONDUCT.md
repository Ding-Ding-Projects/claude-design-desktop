# Code of conduct

## Our standard

Participation in this project requires respectful, precise, and technically useful collaboration. Discuss code, documentation, and product decisions without attacking people. Welcome corrections, distinguish verified facts from proposals, and keep user data and credentials private.

Unacceptable behaviour includes harassment, discrimination, threats, doxxing, publishing private material, credential requests, malicious changes, and attempts to bypass repository or platform security controls.

## Enforcement

Report conduct concerns privately through the repository's available maintainer or security channel. Include links and a factual description, but do not include secrets or private user data. Maintainers may remove content, restrict participation, or escalate a report when needed to protect contributors and users.
